## 7. Remaining Blocker & Resolution Steps for Public Release Publication

### Single Remaining Legal Redistribution Blocker
- **Blocker Description:** Owkin's Phikon-v2 `LICENSE.pdf` Preamble (*"limited to grant non-profit entities with the rights defined hereunder"*) and `Section 1` (*"Non-Commercial excludes any use, sale, lease, license, or other transfer of the Licensed Material, Derivative Works or Results by or to a for-profit organization"*) restrict sharing of Phikon-v2-derived `Results` (`models/*.pth`, `models/*.onnx`, `android/app/src/main/assets/models/fusion_model_fp32.onnx`, and `android/app/src/main/assets/reference_tensors/*.bin`) to qualifying non-profit entities without transfer to for-profit organizations. Because publishing a public GitHub Release (`v1.1.0`) under an individual GitHub account generates un-gated public release archives containing tracked `Results`, public tag/release creation is held **`BLOCKED`** pending either:
  1. Written confirmation / academic institutional non-profit authorization covering public repository release of `Results` under Owkin's ShareAlike terms, **or**
  2. Written clarification / permission from **Owkin Inc.** (`https://www.owkin.com` / `https://huggingface.co/owkin/phikon-v2`).

### Exact Release Commands Once Upstream Redistribution Clearance Is Confirmed
```powershell
git tag -a v1.1.0 -m "EdgeCRC-AI v1.1.0"
git push origin v1.1.0
```
Then create the GitHub Release at `https://github.com/PrajwalGN1/EdgeCRC-AI/releases/new?tag=v1.1.0` with title **`EdgeCRC-AI v1.1.0`** and body copied from `reports/release/RELEASE_NOTES_v1.1.0.md` (do **not** attach restricted model weights, `.bin` tensors, or `.apk` binaries unless explicitly cleared).
