## 1. Executive Gate Determination

1. **Original Software Code License (`PASS`):** Confirmed directly with the repository owner (`Copyright (c) 2026 Prajwal G N`) and implemented in root [`LICENSE`](../../LICENSE) using the exact official **PolyForm Noncommercial License 1.0.0** text (`https://polyformproject.org/licenses/noncommercial/1.0.0`), explicitly scoped to original project-authored software source code, scripts, schemas, tests, and documentation only (**source-available under non-commercial terms, not OSI-approved open source**).
2. **Upstream Foundation Model Compliance (`MODEL_LICENSE.md` — Documented & Scoped):**
   - Direct inspection of the 14-page **Owkin Phikon-v2** [`LICENSE.pdf`](https://huggingface.co/owkin/phikon-v2/blob/main/LICENSE.pdf) confirmed that precomputed patch embeddings (`reference_tensors/*.bin`) and downstream fusion models trained on Phikon-v2 features (`models/*.pth`, `models/*.onnx`, and `android/app/src/main/assets/models/fusion_model_fp32.onnx`) qualify as **`Results`** under `Section 1`.
   - Under `Section 3(c)(2)` and `Section 3(c)(4)`, sharing `Results` requires **ShareAlike** under the **same terms and conditions as the Owkin License** and prohibits imposing *"any additional or different terms or conditions"*. Consequently, PolyForm Noncommercial 1.0.0 is **not** applied to `models/` or `reference_tensors/`.
   - Direct inspection of the **Bio_ClinicalBERT** Hugging Face model card (`license: mit`) and upstream `EmilyAlsentzer/clinicalBERT/LICENSE` confirmed the **MIT License** (`Copyright (c) 2019 Emily Alsentzer`).
3. **Dataset & Dependency Attribution (`PASS`):**
   - Created [`DATA_ATTRIBUTION.md`](../../DATA_ATTRIBUTION.md) containing the verbatim NCI acknowledgment (*"The results shown here are in whole or part based upon data generated by the TCGA Research Network: https://www.cancer.gov/tcga."*) and TCGA Open-Access non-reidentification rules.
   - Created [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md) recording verified versions, upstream projects, licenses, official URLs, and redistribution obligations for all `13` Android/Gradle components, `75` pinned `requirements.txt` packages, and `7` Python export/test toolchain packages.
4. **Public Release Publication Gate (`BLOCKED`):**
   - Owkin's `LICENSE.pdf` Preamble (*"limited to grant non-profit entities with the rights defined hereunder"*) and `Section 1` (*"Non-Commercial excludes any use, sale, lease, license, or other transfer of the Licensed Material, Derivative Works or Results by or to a for-profit organization"*) create a legal redistribution ambiguity for un-gated public GitHub Releases published under an individual developer account (`PrajwalGN1`), because GitHub Releases package tracked `Results` (`models/*`, `reference_tensors/*`) into public download archives accessible without non-profit entity verification.
   - Per conservative compliance rules: existing repository files were **not** automatically deleted, **no** restricted binaries were attached to any new release, and **public `v1.1.0` tag / GitHub Release creation remains `BLOCKED`** until institutional non-profit eligibility or Owkin Inc. clearance is verified.
